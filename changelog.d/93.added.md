- Escalation records: when `factory build` stops on something a person can settle (the coder says it is blocked, the budget runs out, the panel asks for changes a second time, the coder changes nothing, or the suite or behaviour check fails), the work item now moves to `escalated` with a record of the question, the runs, the cost so far, the diff, the last agent outputs and the end of the suite output, instead of a plain `blocked`. Failures outside the item still move it to `blocked` (#93).
- `factory escalations list [--open]`, `show <id>` and `answer <id> --text TEXT|@FILE`. `show` prints a record as Markdown with collapsible sections, `answer` stores the answer and moves the item back to `ready` once no question on it is open, and the next `factory build` gives the coder the answers in the ticket body. Each command takes `--json` (#93).
