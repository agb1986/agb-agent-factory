- Four GitHub tools in `tools/github.py`, all through `gh api` and `GH_TOKEN`. `github.read_issue` and `github.read_pr` are read-only and any agent may hold them; they read only the repository its `origin` names and mark titles, bodies and comments as untrusted text. `github.create_pr` and `github.comment_pr` are outside writes that no model is given: pipeline code makes them through `runtime.outside.write`, which checks that the authorising agent lists the tool, that the target is the pipeline's own repository and not a fork, and that the same write was not already made in this pipeline run, then writes one `outside:<tool>` trace row whatever the outcome. `--dry-run` builds the full request without sending it. `create_pr` pushes one new `factory/<pipeline_run_id>` branch and opens a pull request, a draft when asked, with existing labels only; `comment_pr` posts one review or summary comment and edits it on a rerun. `judge` is now 2.1.0 and lists both writes, and a new `live_github` test marker needs `GH_TOKEN` (#84).
