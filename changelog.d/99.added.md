- test-writer 0.2.0 has a cover mode: `TestWriterInput` takes `mode` (`reproduce`, the default and the old behaviour, or `cover`), and in cover mode `target_paths` and their `coverage` report in place of a finding, and the agent writes passing tests for the uncovered lines (#99).
- `evals.coverage` measures the line coverage of chosen files in the sandbox with the standard library alone, and the `sandbox_tests` grader checks it through `expected.run.coverage`; two cover-mode eval cases use it, one on the new `partly-covered` fixture (#99).
- `pipelines/cover.py` runs the test-writer in cover mode in a clone, measures the coverage before and after in the sandbox, and rejects test files that fail at head and changes to non-test files, each with a tagged trace row; the build loop will call it, and there is no `factory` command for it yet (#99).
