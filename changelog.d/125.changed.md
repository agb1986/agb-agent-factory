- The tool registry is discovered: each `tools/<module>.py` declares its tools in a `TOOLS` tuple of `ToolSpec` values, and `tools.registry` collects them, so adding a tool no longer edits the registry, its sets or the registry test. Changelog entries are written as fragments in `changelog.d/` and collected at release time by `scripts/collect_changelog.py`, so parallel pull requests stop conflicting on `CHANGELOG.md` (#125).
