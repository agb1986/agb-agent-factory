- `technical-feasibility@0.1.0`, a research agent that answers whether an idea can be built in a repository: it reads the code with `git.read_file` and `rg.search`, fetches documentation from an allow-list of ten documentation hosts with `web.fetch`, and returns a verdict (`viable`, `viable_with_constraints`, `not_viable` or `unknown`) with reasons whose facts quote their pages word for word, the constraints the idea depends on, and a spike to run when the documentation does not settle it. It prefers `unknown` to a guess (#104).
