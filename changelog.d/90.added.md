- `product-architect@0.1.0`, a planning agent that turns an idea or raw user feedback into a product requirements document: problem, goals, non-goals, user stories, constraints, risks, and the open questions a person must answer before building. It reads the repository with `git.read_file`, `rg.search`, `deps.graph` and `memory.search`, never invents a requirement the request did not state, and leaves the goals empty when the request contradicts itself (#90).
- The `rubric` grader checks `empty_fields`, fields that must be present and empty, such as the goals of a plan for a request that contradicts itself (#90).
